
# HR Lifecycle Copilot Agent

Welcome to the HR Lifecycle Copilot Agent project.

An AI agent developed in Microsoft Copilot Studio to support managers, HR teams and ICT colleagues with Starter and Leaver processes.

## About the project

The agent guides users through HR lifecycle activities, validates inputs and produces structured outputs to support operational workflows.

## Project documentation

This website brings together the project's architecture, design documentation, demonstration materials and lessons learned.
